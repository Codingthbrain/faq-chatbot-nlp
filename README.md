# faq-chatbot-nlp
An NLP-based FAQ chatbot built using Python, NLTK, and Scikit-learn. The chatbot preprocesses text, matches user questions with the most similar FAQ using TF-IDF and cosine similarity, and returns accurate responses automatically.
# FAQ Chatbot using NLP

This project is a simple AI-powered FAQ chatbot developed using Python. It uses Natural Language Processing (NLP) techniques to understand user questions and find the most relevant answer from a predefined FAQ dataset.

## Features

- Text preprocessing using NLTK
- TF-IDF vectorization
- Cosine similarity matching
- Intelligent FAQ response system
- Simple and beginner-friendly implementation

## Technologies Used

- Python
- NLTK
- Scikit-learn
- Google Colab

## How It Works

1. User enters a question
2. Text is cleaned and tokenized
3. TF-IDF converts text into vectors
4. Cosine similarity finds the closest FAQ
5. Best matching answer is returned

## Example

User Question:
How can I recover my password?

Chatbot Response:
Click on forgot password option to reset your password.
